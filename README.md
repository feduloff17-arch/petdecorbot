# Simple multilingual Telegram request bot

Упрощенный Telegram-бот для заявок на изделие.

Бот автоматически выбирает язык по языку Telegram-профиля клиента:

- русский `ru`;
- английский `en`;
- иврит `he`;
- украинский `uk`.
- испанский `es`;
- итальянский `it`.

Если язык неизвестен, бот использует русский.

## Что собирает бот

1. Имя.
2. Страну.
3. Тип изделия.
4. Размеры.
5. Фото или референсы.
6. Пожелания и сроки.

После этого бот отправляет администратору одну собранную заявку в Telegram. Фото тоже пересылаются администратору.

Администратору заявка приходит на русском, с пометкой языка клиента.

## Настройка

1. Создайте бота через `@BotFather`.
2. Получите токен бота.
3. Узнайте Telegram ID администратора через `@userinfobot`.
4. Скопируйте `.env.example` в `.env`.

В PowerShell:

```powershell
Copy-Item .env.example .env
```

5. Заполните `.env`:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=telegram_id_администратора
```

Если администраторов несколько:

```env
ADMIN_IDS=123456789,987654321
```

## Запуск

Установите зависимости:

```powershell
npm install
```

Запустите бота:

```powershell
npm start
```

## Деплой на Render.com

Для Render лучше использовать `Web Service`. Бот сам переключится в webhook-режим, когда увидит публичный URL Render.

1. Загрузите проект в GitHub.
2. Откройте Render Dashboard.
3. Нажмите `New` -> `Web Service`.
4. Подключите GitHub-репозиторий с ботом.
5. В настройках сервиса укажите:

```text
Runtime: Node
Build Command: npm install
Start Command: npm start
```

6. В разделе `Environment` добавьте переменные:

```env
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=telegram_id_администратора
```

7. Если после первого деплоя бот не отвечает, добавьте вручную:

```env
BOT_WEBHOOK_URL=https://имя-сервиса.onrender.com
```

Адрес `https://имя-сервиса.onrender.com` берется со страницы сервиса в Render.

8. Нажмите `Deploy`.

После успешного деплоя откройте в браузере:

```text
https://имя-сервиса.onrender.com/health
```

Если видите:

```json
{"ok":true}
```

значит сервис живой.

На бесплатном тарифе Render может засыпать после простоя. Первое сообщение после паузы может обработаться с задержкой, пока сервис просыпается.

## Команды

- `/start` - открыть меню клиента.
- `/admin` - проверить, что администратор подключен.

## Как выглядит заявка для администратора

```text
Новая заявка: REQ-...

Язык клиента: английский
Telegram: Имя, @username, ID ...
Имя: ...
Страна: ...
Тип изделия: ...
Размеры: ...
Пожелания и сроки: ...
Фото: 2
```
